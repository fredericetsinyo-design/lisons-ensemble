Android

Télécharger pour Android

⬇ Télécharger l'application (APK)
  1. Touchez le bouton ci-dessus. Le fichier (environ 5 Mo) se télécharge.
  2. Ouvrez le fichier depuis la notification ou le dossier Téléchargements.
  3. Si Android demande une autorisation, touchez Paramètres puis activez « Autoriser cette source », et revenez.
  4. Touchez Installer, puis Ouvrir. Créez votre compte ou connectez-vous.

L'application se met à jour toute seule quand le site évolue : inutile de la réinstaller.

iPhone

Sur iPhone

  1. Ouvrez le site de l'application dans Safari.
  2. Touchez le bouton Partager (le carré avec une flèche).
  3. Choisissez « Sur l'écran d'accueil », puis Ajouter.

L'icône apparaît comme une application. Sur iPhone, utilisez le mode écoute (☾) pour que la lecture continue.
