# Lisons Ensemble

Application web (PWA) de lecture en communauté : import PDF/EPUB, notes dont l'auteur choisit la visibilité, groupes privés sur invitation, lecture vocale avec voix féminine ou masculine.

- Hébergement : GitHub Pages (branche `main`, dossier racine).
- Serveur : Supabase (tables `le_*`, stockage privé `le-books`, fonction `le-signup`).
- Invitation : `https://<compte>.github.io/lisons-ensemble/?code=CODE`.
